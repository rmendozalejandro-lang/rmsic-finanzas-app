# OT Viva · continuidad por interrupción

Este marcador documenta el despliegue que incorpora el control de continuidad de terreno en OT Viva.

Incluye:
- estado local `interrumpida`;
- botón `Marcar interrupción`;
- checkpoint de continuidad;
- reanudación de la misma sesión;
- sincronización del estado con el núcleo Asistente Tralixia.

No modifica la OT formal ni la rama `main`.
